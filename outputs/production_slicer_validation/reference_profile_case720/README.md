# Illustrative case-720 production-slicer record

Case 720 is a validation-partition case retained only as an illustrative case-level demonstration. It is not one of the 250 held-out test cases and is not the source of any reported cohort production-slicer statistic.

This illustrative geometry analysis uses segmentation threshold 0.4. The held-out cohort uses threshold 0.5. The sole source of the manuscript's 250-case PrusaSlicer statistics is `../cohort_250_real/`.

The record demonstrates software-level toolpath generation under the same fixed computational reference profile. It does not represent physical fabrication, bioprinter validation, bioink validation, print-fidelity validation, biological validation, or clinical readiness.
